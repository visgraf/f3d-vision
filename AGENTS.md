# Agent instructions

The canonical working agreement for this repository is
[`CLAUDE.md`](CLAUDE.md).

All coding assistants and autonomous development tools working in this repository
must read and follow `CLAUDE.md` before proposing, modifying, executing, testing,
or committing project work.

If an instruction in another agent-specific file conflicts with `CLAUDE.md`,
`CLAUDE.md` is the project-level authority unless Luiz explicitly states otherwise.
